Command center

The dense, power-user layout. A dark plum command bar carries her name and four live figures; a tab strip splits Overview / Everything I know / Gifts / Family / Memories so no single screen has to hold it all; and a 12-column grid packs small, tight cards at high information density. Half the padding of the editorial layout and roughly twice the content per screen. Least decorative, most efficient — the layout that scales when there are three partners and forty facts each.
