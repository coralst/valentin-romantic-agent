Her page, rebuilt six ways

The current Profile page isn't ugly — it's flat. Every card is the same cream, the same size, the same weight, so nothing tells you where to look, and two panels dead-end in an empty state. These mockups fix that with one idea: colour carries meaning. Each knowledge domain owns a hue, so grouping happens before you read a word. On top of that, every screen gets one hero figure, deliberate density variation, and empty states that ask a better question instead of apologising. All six files are static HTML+CSS — open them straight in a browser.
