Read the last row first. The model is identical on both sides, which is what makes any latency or cost delta attributable to the orchestration layer rather than to a different model.
AgentCore Identity is drawn as a hop it is not. Inbound auth is configuration on the runtime, not a network box; it earns a card here only because it is the thing that lets the browser reach the runtime without holding AWS credentials.
Gateway is absent on purpose. It exists to expose tools, and Valentin has none yet — drawing it would sketch an architecture for an agent that does not exist.
