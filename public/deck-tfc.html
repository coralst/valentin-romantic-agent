03 · Use case

Use case

The problem

The details arrive in conversation

Mentioned once, in passing, months before they matter.

Why a reminder app isn't enough

"Anniversary" on the day is too late

You needed lead time you chose, and options you can act on.

The pattern

Extract, remember, act later

Romance is the demo. The same shape fits onboarding and renewals.

Why an agent and not a form with a cron job: unstructured input arriving over weeks, a plan whose next tool depends on what came back, and a human in the loop before anything sends.

05 · Architecture

Architecture

One URL, two engines, switchable from the UI. Same model, same guardrail, same table — so every difference is the platform.

Engine A · my glue code  →  Engine B · AgentCore
  • ECS Fargate → Runtime
    one always-on task → one microVM per session
  • DynamoDB → Memory
    my store → a managed strategy
  • A 2nd Bedrock call → Memory
    my extraction pass → extraction I don't write
  • In-process registry → Gateway
    functions → tools over MCP, on Lambda

10 · Comparison · Security

Comparison — Security

One guardrail, both engines. The work was tuning it — the safe default broke the product.

6
content filters, measured

At HIGH, SEXUAL blocked "her ring size is 6" — a field the agent asks for.

5
PII entities blocked

Card, SSN, phone, and both AWS key types.

3
regexes replacing one entity

ADDRESS read "saving for Kyoto" as an address.

7
tools that cannot act alone

Every write awaits a human yes.

Known gap · ALB listener is HTTP

TLS terminates at CloudFront; the hop to the ALB doesn't.

Known gap · Cognito isn't enforced

The front door is a demo login, not a real one.

Known gap · secrets by hand

Populating Google OAuth is still manual after a deploy.

NAME, AGE and EMAIL are deliberately not blocked — they are this agent's subject matter. Every decision is a dated comment in safety-stack.ts.

13 · Lessons learned

Lessons learned

01
The workflow cost more than the product

32 of 57 PRs went into the agents, hooks and merge gate. Budget for building the process.

02
What AgentCore sold me was blast radius, not money

187× collapses to 13.5× once fixed costs amortise. The durable win is one microVM per session.

03
Plan with the strong model, execute with the cheap one

Stuck in a loop, more of the same model didn't help — a stronger planner did. Model choice is per-phase.

04
Don't trust "healthy"

Engine B was green for weeks and had never served a turn. Four faults, each hiding the next.
